# 登录账号后的再次实测

2026-10-09，Asia/Shanghai，约 23:02–23:38。用户要求手动切换内容，跳过广告及剧集之间插入的直播卡片，并处理横屏布局。

本轮实际完成 5 次广告自动跳过并恢复播放。直播入口规则已补充，但没有采集到真正的直播卡片，运行效果未验证。横屏居中窄窗口的广告自动跳过成功；原生全宽横屏播放器只验证了播放、控件和手动切集，未出现广告样本。

## 实际发现与修改

最初在《出狱后，厉先生宠她上瘾》中采集到真实广告：底部节点 `com.phoenix.read:id/aq8` 显示“8秒后可继续上滑观看短剧”，倒计时后变为“上滑继续观看短剧”。见 [倒计时画面](portrait-02.png)、[就绪节点](portrait-ad-ready.json) 和 [就绪画面](portrait-ad-ready.png)。原规则限定顶部 30%，会漏掉这类广告。

已调整 [PageRules.java](../../tools/android-probe/src/io/adpass/probe/PageRules.java) 和 [ProbeService.java](../../tools/android-probe/src/io/adpass/probe/ProbeService.java)：

- 只使用可见、有效且完整处于当前应用窗口内的节点，过滤前后集缓存的屏外节点；匹配不再限定顶部。
- 区分广告预告、倒计时、可跳过提示和普通内容，识别“秒”和“s”两种倒计时格式；倒计时不自动上滑。
- 明确的继续上滑提示需来自已验证的 `aq8` 节点，或同时有“广告”标记。连续两轮命中、窗口保持相同后才上滑，配置冷却 8 秒。
- 手势按应用窗口位置和尺寸计算，而非写死竖屏坐标；重新核对窗口位置，旋转中止旧窗口的操作。
- 直播卡片识别使用 APK 中已确认的 `jjy` 节点及“点击进入直播间”文案，或“直播中/正在直播”与明确直播入口的组合。不会把“直播间同价”当成直播卡片。
- 保存分类、窗口位置、节点可见性、手势坐标、自动操作前后截图和完成回调。

节点可见性 API 的定义可查 [Android 官方文档](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo#isVisibleToUser())。具体过滤、判断和手势结果来自本轮本地代码与模拟器记录。

## 横屏范围

原生横屏通过视频的“全屏观看”进入，窗口为 `[0,0,2340,1080]`。普通播放器使用下一集按钮；上滑不会像竖屏信息流一样切集。已使用下一集按钮采集普通播放页，见 [原生横屏控件](native-landscape-controls.png)、[下一集结果](native-landscape-next-button.json)。没有在这套原生横屏播放器中收到广告或直播，因此不能宣称其所有插入布局已验证。

另外临时旋转了锁定竖屏的剧集，Android 将应用放入居中窄窗口 `[858,0,1619,1080]`。真实广告提示移到窗口底部，本轮在该窗口内自动跳过成功：手势从 `(1238.5,810)` 到 `(1238.5,270)`。见 [旋转后的操作前截图](auto-rotated-before.png)、[操作后截图](auto-rotated-after.png)、[恢复节点](after-auto-rotated.json)。这验证了窗口偏移及旋转后的坐标处理，不等于全宽原生横屏广告验证。

## 直播范围

检查了剧集之间的插入内容和推荐流，也按用户说明重点检查剧集间直播卡片。没有观察到真正的直播预览；唯一带“直播”文字的运行时样本为广告商品标签“直播间同价”，未计入直播。

APK 资源确认了 `string/bbm` 为“点击进入直播间”、`string/c3v` 为“直播中”，且 `res/l/bnp.xml` 将直播入口文案与 `id/jjy` 关联。证据见 [live-resource-evidence.txt](live-resource-evidence.txt)。这是静态资源证据，不能证明实际直播卡片一定暴露该节点、同时显示这些控件或接受同样的手势。直播规则已装入模拟器，但实际跳过直播仍待真实卡片验证。

## 验证与收尾

探针构建、APK 签名验证通过，39 个真实页面记录的分类回放通过，覆盖普通竖屏播放、推荐流、广告倒计时、可跳过提示、原生横屏普通内容、旋转窄窗口和跳过后恢复画面。测试命令：`python3 tools/android-probe/tests/replay.py`。没有直播运行时测试样本。

本轮未发现探针错误或手势取消事件。8 秒冷却已配置，未单独验证高频连续命中下的冷却边界；没有真机性能、耗电或长期误触率数据；OCR 未实现，未覆盖无法通过节点读取的未知广告。

自动规则和无障碍服务已关闭，旋转配置恢复为 `ignoreOrientationRequest=false`、`fixed-to-user-rotation=default`、`user-rotation=free`，登录数据保留。红果停在第33集的 [暂停画面](final-paused.png)，模拟器继续运行。复用命令见 [README.md](../../README.md)。
