# 0.1.0 初版验收

时间：2026-10-09 夜间至 2026-10-10 00:09（Asia/Shanghai）。Android 14 / API 34 ARM64 专用模拟器 emulator-5554，红果 7.3.9.32；保留用户此前登录的账号。旧探针已关闭，本轮测试的是实际交付包 `io.adpass.app`。

## 结果

- 离线编译、APK 签名验证及模拟器安装通过。最低 API 26、目标 API 34、debuggable=false。APK 声明的应用权限只有可选通知权限；无截图能力、网络或录音权限。参见 `apk-badging.txt`。
- 24 项动作门控测试、39 个真实页面分类回放全部通过，输出在 `rule-tests.txt`。覆盖突发事件不能取代确认、确认中断、窗口变化、冷却边界、暂停、其他应用、锁屏、屏幕关闭、重叠手势，以及直播/全宽横屏不执行。
- 首次安装计数 0、自动开关关闭，无障碍尚未开启；`initial.png`。权限说明可打开系统无障碍设置，列表显示“ADPass 广告助手”；`guide.xml` / `accessibility-settings.xml`。
- 无障碍开启后仍保持暂停；12 秒选项切换后返回应用仍选中，`cooldown-persist.png`。随后切换 20 秒并恢复 8 秒。
- 使用实际开关开启，点击“打开红果”可进入原有剧集。手动上滑切集；应用记录 00:02:21 和 00:03:32 两次手势完成。第二次测试直接观察到切集进入商品广告（`manual-next-02.png`），随后未手动操作，回到第 36 集播放（`ad-observed.png`），应用计数为 2（`after-ad-count.png`）。第一条完成记录也计入 2，但未独立截取其完整广告前后过程，不将其列为第二次完整恢复播放证据。
- 操作记录显示两次完成时间、开启及暂停，`logs.xml` / `logs.png`。页面不保存或展示账号、剧集内容。
- 通过界面申请通知权限，系统弹窗正常（`notification-permission.png`）；再次开启后运行通知显示“暂停”（`notification.png`）。点击实际通知暂停按钮后运行通知消失，应用开关回到关闭（`final.png`），累计计数保持 2。
- 本轮 AndroidRuntime 检查未见应用崩溃，`crash-check.txt`。测试完成后模拟器留在 ADPass 页面，自动跳过关闭，无障碍服务保留开启，冷却 8 秒，测试计数保留 2。新设备安装仍从关闭和计数 0 开始。

## 边界

用户指定先 pending 的直播卡片和原生全宽横屏广告，本轮不追加复现测试，本版不启用相应自动操作。门控测试不能代替真实场景覆盖。截图与 UI 层级是 ADB 验收材料；应用不采集截图。

仅 Android 14 模拟器上实测；未验证 Android 8–13、真机省电策略、厂商无障碍限制或长期运行功耗。初版适合继续试用和收集反馈，尚未发布应用商店。
